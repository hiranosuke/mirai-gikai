# 「このサイトについて」(/about) ページ新設 設計書

作成日: 2026-06-15
対象: みらい議会＠さいたま市（さいたま市PoC、非公式fork）

## 背景・目的

さいたま市版のローカライズ過程で、チームみらい本家への外部リンク（公式Note・寄附等）を「誤認を招く」として除去した（PR #5）。その結果、本プロダクトにおけるチームみらいの貢献度・出自が見えなくなり、現状は footer の免責文言「これは政党チームみらいが運営しているものではありません」という **否定的な距離表現だけ** が残った。

本来必要なのは、チームみらい発のプロダクト（OSS）を活用させてもらっているという **敬意・出自のクレジット** と、特定政党の応援目的ではないという **中立性** の両立である。これを専用ページとして明示する。

FORK_GUIDELINES.md（AGPL-3.0 第7条に基づく追加条件）の要件とも整合させる:
- 必須: 免責文言「これは政党チームみらいが運営しているものではありません」の表示
- 推奨: 本家「みらい議会」(https://gikai.team-mir.ai/) へのリンク

## 確定した要件（ブレストでの決定事項）

| 論点 | 決定 |
|------|------|
| 配置・粒度 | 専用「このサイトについて」(/about) ページを新設。footer から導線 |
| トーン | 敬意＋中立明記（出自への感謝と、応援目的でない中立性を同じ重みで明示） |
| 参照リンク | チームみらい公式Note / チームみらい公式サイト / 本家「みらい議会」（寄附は中立性優先で **載せない**） |
| スコープ外 | privacy/terms の「当組織＝チームみらい」整合（運営主体の確定が必要なため別タスク）、AIプロンプト等の文言 |

## 技術構成（既存パターン踏襲）

- **ページ**: `web/src/app/(main)/about/page.tsx`
  - 既存の terms/privacy ページと同様、`LegalPageLayout` / `Container` / `LegalSectionTitle` / `LegalParagraph` / `LegalList` を再利用した薄い構成。シンプルな静的ページのため feature ディレクトリ化はしない。
  - `metadata`（title / description）を設定。
- **ルート登録**: `web/src/lib/routes.ts` に `about: () => "/about" as const` を追加。
  - `routes.test.ts` が page.tsx とルート関数の同期を検証するため必須。
- **footer導線**: `web/src/components/layouts/footer/footer.config.ts` の `primaryLinks` に「このサイトについて」→ `routes.about()` を追加。
  - 副次効果として、PR #5 で primaryLinks が「TOP」1件のみになっていた中途半端な状態が解消される。
- **外部リンク**: `web/src/config/external-links.ts` に参照リンクを定義。
  - `TEAM_MIRAI_NOTE`（チームみらい公式note: `https://note.com/team_mirai_jp`）
  - `TEAM_MIRAI_OFFICIAL`（チームみらい公式サイト: `https://team-mir.ai`）
  - 本家「みらい議会」(`https://gikai.team-mir.ai/`) は footer disclaimer の既存ハードコード値を定数化して共通参照（`MIRAI_GIKAI_HONKE` 等）するか、/about 用に同値を定義。実装時に既存 footer.tsx の値と重複しないよう共通化する。

## ページ構成・本文（確定ドラフト）

見出し: **このサイトについて**

### 1. このサイトの目的
> みらい議会＠さいたま市は、さいたま市議会でいま何が議論されているかを、できる限りわかりやすく伝えることを目的とした非公式のサイトです。さいたま市政に関心を持つ有志が、公開されている情報をもとに作成・運営しています。

### 2. 「みらい議会」とチームみらいについて
> 「みらい議会」は、政党チームみらいが開発・運営している、国会での議論を市民にわかりやすく届けるためのプロジェクトです。本サイトはその仕組みを、さいたま市議会向けに活用したものです。

### 3. このサイトとチームみらいの関係
> 本サイトは、チームみらいがオープンソース（AGPL-3.0）として公開している「みらい議会」のソースコードをフォークし、さいたま市向けに改変して運営しています。有益なプロダクトをオープンソースとして公開してくれたチームみらいに、敬意と感謝を表します。
>
> 一方で、本サイトはチームみらいを応援・宣伝することを目的に立ち上げたものではありません。さいたま市議会の議論を可視化し、市民のみなさんが市政により関心を持てるようにすることを、独立した立場で目指すものです。運営の主体・方針はチームみらいとは独立しており、**これは政党チームみらいが運営しているものではありません。**

### 4. 関連リンク
- チームみらい公式note（`TEAM_MIRAI_NOTE`）
- チームみらい公式サイト（`TEAM_MIRAI_OFFICIAL`）
- 本家「みらい議会」（`gikai.team-mir.ai`）

> リンクはいずれも外部リンク（`target="_blank"` / `rel="noreferrer"`）。インラインカラーコード・`<button>`・インラインSVG禁止（CLAUDE.md UI規約）に従い、必要なアイコンは `lucide-react`、色はカラートークンを使用する。
