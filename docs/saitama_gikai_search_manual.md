# さいたま市議会資料検索システム 利用マニュアル

調査日: 2026-06-14  
対象システム: [さいたま市議会資料検索システム / DiscussCabinet](https://www.discusscabinet.net/saitama/)  
想定読者: さいたま市民向けの議会資料キュレーションサイトを作る人、または議会資料を自分で探したい市民

## 1. このシステムでできること

さいたま市議会の資料検索システムは、DiscussCabinet という文書管理システム上に構築されている。公開画面では、主に以下ができる。

- 新着資料を確認する。
- キャビネットとフォルダをたどって資料を閲覧する。
- 全キャビネット横断、またはキャビネット単位で資料を検索する。
- 文書詳細画面からPDF等の添付ファイルを開く。

システム内の公式マニュアルでは、DiscussCabinet は文書をカテゴリごとに分類して管理するシステムと説明されている。管理単位は大きい順に `キャビネット > フォルダ > 文書 > 添付ファイル` と考えると理解しやすい。

公開利用では、登録・編集・削除・検索条件保存などの管理者向け機能は基本的に使わない。市民向けには、閲覧、検索、PDF確認に絞って案内するとよい。

このシステムは、市民が日常語から資料を探すためのポータルというより、議会・行政側の文書分類を外部から閲覧できるようにした文書保管庫に近い。市民向けキュレーションサイトでは、操作方法を案内するだけでなく、資料の意味、最終状態、関連する市公式ページを整理して補うことが重要になる。

## 2. 画面の全体構造

トップメニューは3つ。

| メニュー | 役割                                           | 市民向けの使いどころ                           |
| -------- | ---------------------------------------------- | ---------------------------------------------- |
| 新着情報 | 最近追加された資料をキャビネット別に確認する   | 会期中に新しい議案、質問通告、審議結果を追う   |
| 文書一覧 | キャビネットとフォルダを手でたどる             | 年、定例会、委員会名が分かっているときに使う   |
| 詳細検索 | キーワード、件名、日付、フォルダ範囲で検索する | テーマ、事業名、議員名、請願、予算などから探す |

公開画面で見える主なキャビネットは次のとおり。

| キャビネット |  ID | 主な中身                                         | 優先度         |
| ------------ | --: | ------------------------------------------------ | -------------- |
| 本会議       |   1 | 議案、質問通告書、議事日程、請願、審議結果など   | 高             |
| 委員会       |   2 | 常任委員会、特別委員会、予算委員会、要求資料など | 高             |
| マニュアル   | 721 | DiscussCabinet ユーザマニュアル                  | 低、操作確認用 |

新着情報では主に `本会議` と `委員会` を見る。`マニュアル` は議会資料ではなく、システム操作の説明資料として扱う。

## 3. 文書データの構造

文書一覧や検索結果では、文書はおおむね次の情報で表示される。

| 項目         | 意味                                                 |
| ------------ | ---------------------------------------------------- |
| 登録フォルダ | `/本会議/令和８年/６月定例会/審議結果/` のような階層 |
| 件名         | 文書タイトル。検索・分類で最も重要                   |
| 日付         | 文書に付与された日付                                 |
| 添付         | PDF等のファイルがあるか                              |
| 詳細         | 文書詳細画面を開くボタン                             |

文書詳細画面では、さらに次の情報が見える。

- 文書ID
- ファイルID
- フォルダID
- 件名
- 日付
- ファイル名
- フォルダ名
- 本文テキスト
- サイズ

キュレーションサイト側で記録するなら、最低限 `件名`、`日付`、`登録フォルダ`、`文書ID`、`ファイルID`、`取得確認日` を保持すると後で追跡しやすい。

## 4. フォルダ構造

### 4.1 本会議

本会議は、年ごと、定例会ごとに整理されている。

観測できた基本階層:

```text
本会議
  令和８年
    ２月定例会
    ６月定例会
  令和７年
    ２月定例会
    ６月定例会
    ９月定例会
    12月定例会
  令和６年
  令和５年
  令和４年
  令和３年
  令和２年
  令和元年（平成31年）
  平成30年
  平成29年
```

定例会フォルダの中は、例えば令和8年6月定例会では次のように分かれていた。

```text
本会議 / 令和８年 / ６月定例会
  議案書等（告示日配付分）
    市長提出議案
    補正予算議案関連
  一般質問通告書
  ６月３日
  ６月４日
  ６月８日
  ６月９日
  ６月10日
  審議結果
```

2月定例会では `代表質問通告書` があり、6月定例会では `一般質問通告書` が見える。質問種別は会期によって変わるため、質問を探すときは定例会フォルダ直下を確認する。

### 4.2 委員会

委員会は、年ごと、委員会名ごとに整理されている。

令和8年で観測できた主な委員会:

- 総合政策委員会
- 子ども文教委員会
- 市民生活委員会
- 保健福祉委員会
- まちづくり委員会
- 予算委員会
- 議会運営委員会
- 決算特別委員会
- 政治倫理特別委員会
- 大都市行財政将来ビジョン特別委員会
- 大宮駅グランドセントラルステーション化構想特別委員会
- 市庁舎等整備検討特別委員会
- 超高齢社会に向けた公共交通の在り方検討特別委員会
- 議会改革推進特別委員会

年によって委員会名や特別委員会の有無は変わる。テーマを追う場合は、キーワード検索だけでなく、該当する特別委員会のフォルダも直接確認する。

予算委員会の例:

```text
委員会 / 令和8年 / 予算委員会
  ２月定例会
  ６月定例会
    ６月４日
    ６月８日
    予算委員会要求資料
```

`予算委員会要求資料` は、市民向けキュレーションで特に重要。会派や委員が行政に求めた資料がまとまるため、議案本文だけでは見えにくい論点が出やすい。

### 4.3 マニュアル

```text
マニュアル / マニュアル
  DiscussCabinet ユーザマニュアル
```

操作方法の確認用。市民向けサイトでは通常、議会資料として扱わない。

## 5. 基本の探し方

### 5.1 最新資料を確認する

1. トップメニューで `新着情報` を開く。
2. `本会議` または `委員会` を選ぶ。
3. 表示された新着文書から、件名と日付を確認する。
4. 必要な文書は `詳細` から文書詳細を開き、PDFを確認する。

会期中はこの画面を最初に見る。特に、議案、質問通告書、審議結果、委員会要求資料は更新タイミングが集中する。

### 5.2 年・会議名から探す

1. `文書一覧` を開く。
2. `本会議` を選ぶ。
3. 年を選ぶ。
4. 定例会を選ぶ。
5. 目的に応じて `議案書等`、`質問通告書`、日付フォルダ、`審議結果` を開く。

例: 令和8年6月定例会の補正予算を探す場合

```text
文書一覧
  本会議
    令和８年
      ６月定例会
        議案書等（告示日配付分）
          補正予算議案関連
```

調査時点では、このフォルダに次の文書があった。

- `01_令和8年さいたま市議会６月定例会補正予算議案の概要`
- `02_さいたま市一般会計特別会計補正予算及び補正予算説明書`
- `03_さいたま市水道事業会計補正予算及び補正予算説明書`
- `04_さいたま市下水道事業会計補正予算及び補正予算説明書`

### 5.3 テーマから探す

1. `詳細検索` を開く。
2. 最初は `全キャビネット検索` を使う。
3. キーワードを入れる。複数語は半角スペースで区切る。
4. AND / OR を選ぶ。
5. ヒットが多い場合は、キャビネット別件数を見て `本会議` または `委員会` に絞る。
6. さらに日付やフォルダで絞る。

広い語はヒットが多くなる。調査時点の例:

| キーワード | 総ヒット数 | 本会議 | 委員会 | コメント                                 |
| ---------- | ---------: | -----: | -----: | ---------------------------------------- |
| 補正予算   |       1303 |    673 |    630 | 本会議の議案と委員会要求資料の両方を見る |
| 市庁舎     |        224 |     63 |    161 | 市庁舎等整備検討特別委員会を併用する     |
| 大宮駅     |       1446 |    399 |   1047 | 大宮駅GCS関連でヒットが非常に多い        |

最初から1語だけで結論を出さない。市民向けに使うなら、検索結果数、見たフォルダ、採用した資料の基準を記録する。

### 5.4 請願を探す

おすすめは本会議のキャビネット単位検索。

1. `詳細検索` を開く。
2. `キャビネット単位検索` で `本会議` を選ぶ。
3. キーワードに `請願` を入れる。
4. 日付範囲を会期に合わせる。
5. サブフォルダは `含む` のまま検索する。

例: 2026年6月1日から2026年6月30日まで、キーワード `請願` で検索すると、調査時点では6件が表示された。

- `令和８年６月定例会請願審議結果一覧`
- `02_R080603会期予定表`
- `01_R080604議事日程（第２号）`
- `03_R080604委員会審査結果報告一覧`
- `05_R080604請願文書表`
- `06_R080604請願付託表`

請願は、`請願文書表`、`請願付託表`、`請願審議結果一覧` の3点をセットで見ると流れを追いやすい。

## 6. 詳細検索の使い分け

### 6.1 全キャビネット検索

全体像をつかむための入口。検索項目はシンプル。

- キーワード
- AND / OR
- 関連語辞書を使う / 使わない

使い方:

- 初回調査では全キャビネット検索を使う。
- ヒット数とキャビネット別件数を見る。
- `本会議` と `委員会` のどちらを深掘りするか決める。

注意:

- 広い語ではヒットが多く、すぐに個別文書へ行くと迷いやすい。
- 結果画面はまずキャビネット別の件数を出し、キャビネットを選ぶと文書一覧へ進む。

### 6.2 キャビネット単位検索

資料の種類や期間が分かっているときはこちらを使う。

主な検索項目:

- キャビネット / フォルダ名
- サブフォルダを含む / 含まない
- キーワード
- AND / OR
- 件名
- 日付範囲
- 関連語辞書

使い方:

- `本会議` で会期中の資料を探す。
- `委員会` で特定テーマの審査資料を探す。
- `件名` に文書タイトルの一部を入れて絞る。
- `日付` で会期や委員会開催日を絞る。

`サブフォルダを含む` は原則オンにする。年フォルダや定例会フォルダを指定した場合、資料はさらに下層フォルダに入っているため、オフにすると見落としやすい。

### 6.3 AND / OR の選び方

| 選択 | 使う場面                       | 例                 |
| ---- | ------------------------------ | ------------------ |
| AND  | 複数語をすべて含む資料に絞る   | `補正予算 子育て`  |
| OR   | 表記ゆれや関連テーマを広く拾う | `市庁舎 庁舎 移転` |

複数キーワードは半角スペースで区切る。日本語の全角スペースでは意図通りに分割されない可能性があるため、半角スペースで統一する。

### 6.4 関連語辞書

関連語辞書はキーワード検索にだけ使われる。公式マニュアル上も、関連語辞書は検索語の拡張に関する機能として扱われている。

使う場面:

- 表記ゆれがありそうな語を広く拾いたい。
- 初回の探索で漏れを減らしたい。

使わない場面:

- 既に資料名やフォルダ名が分かっている。
- ヒットが多すぎる。
- 件名や日付で厳密に絞りたい。

## 7. 注目すべき資料の探し方

### 7.1 議案

市の新しい条例、補正予算、契約、指定管理、財産取得などを追う基本資料。

探し方:

```text
文書一覧
  本会議
    年
      定例会
        議案書等（告示日配付分）
          市長提出議案
```

見るべき資料:

- 提出議案一覧
- 議案本文
- 議案説明資料がある場合は関連資料

キュレーション観点:

- 市民生活への影響が大きい条例改正
- 金額の大きい契約・事業
- 公共施設、学校、福祉、交通、まちづくりに関わる議案

### 7.2 補正予算

年度途中の政策変更、国補助金、物価高騰対策、施設整備などが見える。

探し方:

```text
本会議
  年
    定例会
      議案書等（告示日配付分）
        補正予算議案関連
```

あわせて見る:

```text
委員会
  年
    予算委員会
      定例会
        予算委員会要求資料
```

予算委員会要求資料は、会派や委員が何を問題視したかを知る入口になる。議案本文と要求資料をセットで見ると、市民向け解説の質が上がる。

### 7.3 決定後の予算・詳細内訳

予算委員会の資料は、審議中の論点や追加説明を知るための資料であり、最終的に決まった予算そのものを確認する入口ではない。最終状態を確認するには、議会側の審議結果と、市公式サイトの予算・決算ページを組み合わせる。

「最終的に決まった予算」には、次の2つの意味がある。

| 見たいもの                               | 確認する場所                                                                             | 使い方                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 議会で可決された当初予算・補正予算       | 議会資料検索システムの `本会議 / 年 / 定例会 / 審議結果 / 議案審議結果一覧`              | 原案可決、修正可決、否決などを確認する                       |
| 可決後に市が公開する予算書・予算説明書   | さいたま市公式サイトの [予算](https://www.city.saitama.lg.jp/006/007/011/001/index.html) | 年度別に `当初予算`、`補正予算`、`当初予算の概要` を確認する |
| 年度中の補正を反映した予算現額と執行結果 | さいたま市公式サイトの [決算](https://www.city.saitama.lg.jp/006/007/011/002/index.html) | 決算、行政報告書で支出済額、不用額、繰越などを確認する       |

調査時点の例では、さいたま市公式サイトの [令和8年度当初予算](https://www.city.saitama.lg.jp/006/007/011/001/021/p129189.html) に「令和8年3月12日に原案のとおり可決」と明記され、一般会計・特別会計、水道事業、病院事業、下水道事業の予算及び予算説明書PDFが公開されている。

詳細内訳を確認する順番:

1. [令和8年度当初予算の概要](https://www.city.saitama.lg.jp/006/007/011/001/021/p128060.html) のような概要ページで、全体規模、重点事業、各局別資料を把握する。
2. `当初予算` ページの `一般会計特別会計予算及び予算説明書` を開き、会計別、歳入歳出、款・項・目・節、財源内訳、継続費、債務負担行為、地方債などを確認する。
3. 補正予算の場合は、[令和8年6月補正予算](https://www.city.saitama.lg.jp/006/007/011/001/021/p130849.html) のような補正予算ページで、補正予算議案の概要と補正予算説明書を確認する。
4. 実際にいくら使われたかは、決算ページの年度別資料を見る。例として [令和6年度決算](https://www.city.saitama.lg.jp/006/007/011/002/p124022.html) には、一般会計決算の概況、行政報告書、継続費精算報告書などが掲載されている。

確認できる粒度:

- 当初予算・補正予算の総額、会計別内訳
- 歳入・歳出の款、項、目、節
- 事業名、主な事業の概要、各局・区別の予算
- 特定財源、一般財源、地方債、債務負担行為、継続費
- 決算段階の予算現額、支出済額、翌年度繰越額、不用額、不用額の理由

確認しにくい粒度:

- 個別契約、個別支払先、請求書単位の支出
- 予算執行中のリアルタイムな支出状況
- 内部査定資料や庁内検討資料のすべて

この粒度が必要な場合は、決算・行政報告書に加えて、入札・契約情報、事務事業評価、情報公開請求を組み合わせる。市民向けサイトでは、予算委員会要求資料を「論点」、議案審議結果を「最終状態」、市公式予算ページを「確定した予算書・説明書」、決算ページを「執行結果」として分けて扱うと分かりやすい。

関連して、さいたま市公式サイトには [予算に対する市議会会派要望への対応状況](https://www.city.saitama.lg.jp/006/007/011/009/index.html) もある。例として [令和8年度当初予算等に対する市議会会派要望等への対応状況](https://www.city.saitama.lg.jp/006/007/011/009/p129433.html) では、会派別の要望と市の回答PDFが公開されている。予算委員会資料とは別系統だが、会派が何を求め、市がどう回答したかを追う資料として有用。

### 7.4 質問通告書

議員がどのテーマを取り上げるかを事前に把握できる。

探し方:

```text
本会議
  年
    定例会
      代表質問通告書
      一般質問通告書
```

見る観点:

- 地域課題、学校、保育、福祉、交通、防災などの市民生活テーマ
- 何人の議員が同じテーマを扱っているか
- 質問順、質問時間、ページ番号

### 7.5 審議結果

議案や請願が最終的にどうなったかを確認する資料。

探し方:

```text
本会議
  年
    定例会
      審議結果
```

見るべき資料:

- 議案審議結果一覧
- 請願審議結果一覧

市民向けサイトでは、議案紹介ページに審議結果への参照を必ず追加する。提出時点の情報だけだと、可決・否決・継続審査などの最終状態が分からない。

### 7.6 請願

市民の意思表示が議会でどう扱われたかを見る資料。

探し方:

- キーワード検索: `請願`
- 本会議の日付フォルダ: `請願文書表`、`請願付託表`
- 本会議の審議結果フォルダ: `請願審議結果一覧`

市民向けサイトでは、請願のテーマ、提出者名が公開されている場合の扱い、付託先委員会、結果を丁寧に扱う。個人情報の再掲載には注意する。

### 7.7 委員会要求資料

議案本文よりも背景情報や論点が見つかることが多い。

探し方:


会派別、委員別に資料が分かれることがある。調査時点の令和8年度6月補正予算では、目次のほか、複数会派・委員別の提出要求資料が並んでいた。

### 8.4 直リンクの扱い

このシステムは画面遷移の多くがPOST送信で動く。文書一覧や文書詳細は、URLだけでは同じ状態を再現しにくい。

そのため、市民向けサイトでは次のようにする。

- 原典リンクはシステム入口へのリンクを基本にする。
- 資料ごとに `フォルダパス`、`文書ID`、`ファイルID` を記録する。
- 直リンクが一時的に動いても、永続URLとして過信しない。
- PDFを引用・再配布する場合は、さいたま市サイトの著作権・利用条件を確認する。

### 8.5 使いにくさを補うサイト設計

議会資料検索システムは、資料そのものへの到達はできるが、市民が知りたい単位で情報が整理されているわけではない。キュレーションサイト側では、システムの弱点を前提に、情報を再構成する。

| 使いにくい点                                     | 市民側で起きる問題                                            | サイト側で補うこと                                                                      |
| ------------------------------------------------ | ------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| URLだけで検索結果や文書詳細を共有しにくい        | 「この資料を見て」と案内しても再現しづらい                    | システム入口に加えて、キャビネット、年度、会期、フォルダパス、文書ID、PDF名を記録する   |
| 議会用語とフォルダ構造を知らないと探せない       | `本会議`、`委員会`、`審議結果`、`要求資料` の意味が分からない | 市民向けのテーマ名、短い説明、探す順番を付ける                                          |
| 予算委員会資料、予算書、決算が別々に置かれている | 予算が最終的にどう決まったか、実際に使われたかがつながらない  | 1つの事業・議案ページに、委員会資料、議案審議結果、市公式予算ページ、決算ページを束ねる |
| 検索語に依存しすぎる                             | 行政用語を知らないと必要資料に届かない                        | 同義語タグを持つ。例: `子育て` と `こども未来局`、`公共交通` と `地域公共交通`          |
| PDFの中に重要情報が埋まっている                  | 検索結果の件名だけでは内容や重要性が分からない                | PDFごとに要約、金額、対象地域、関係局、論点を抽出する                                   |
| 資料名が似ている                                 | 概要、議案本文、説明書、審議結果の区別がつきにくい            | `審議前資料`、`審議結果`、`可決後予算書`、`執行結果` のように役割ラベルを付ける         |

市民向けページでは、資料単位ではなく、なるべく「テーマ」または「事業」単位で見せる。

推奨する1ページの構成:

| 表示項目         | 内容                                           |
| ---------------- | ---------------------------------------------- |
| テーマ名         | 例: 令和8年6月補正予算の新庁舎整備関連         |
| 何が決まるのか   | 議案や予算の市民向け要約                       |
| 金額             | 当初予算額、補正額、債務負担行為、継続費など   |
| 現在の状態       | 提出、委員会審査、原案可決、修正可決、否決など |
| 原典資料         | 議案本文、予算説明書、委員会要求資料、審議結果 |
| 市公式資料       | 予算ページ、決算ページ、会派要望対応状況       |
| 市民生活への関係 | 対象地域、対象者、サービス、施設、負担の変化   |
| 確認日           | 情報を確認した日付                             |

特に予算関連では、次の4分類で表示すると混乱が少ない。

| 役割ラベル | 対応する資料                             |
| ---------- | ---------------------------------------- |
| 論点       | 予算委員会要求資料、会派要望への対応状況 |
| 提案内容   | 議案本文、補正予算議案の概要、予算説明書 |
| 最終状態   | 議案審議結果一覧                         |
| 執行結果   | 決算、行政報告書、決算の概況             |

この整理により、利用者は「資料を探す」のではなく、「あるテーマについて、提案、審議、決定、執行結果を順に読む」体験に近づく。

## 10. 注意点

- さいたま市サイトの推奨環境では、最新の Edge、Chrome、Firefox、Safari、JavaScript有効、標準文字サイズ、1024×768ピクセル以上の解像度などが示されている。JavaScriptを無効にすると一部機能が正確に動作しない可能性がある。
- 検索フォームの年選択肢は、調査時点で2017年から2030年まで表示されていた。実際の資料収録範囲はフォルダと検索結果で確認する。
- PDF本文のテキスト抽出は、文書詳細の `本文テキスト` に入るが、抜粋や文字化けがある。重要資料は必ずPDF本体を開いて確認する。
- キーワード検索は便利だが、広い語ではヒット数が非常に多い。件名、日付、フォルダ、キャビネットを併用する。
- 市民向けに要約する場合は、議案本文だけでなく、審議結果と委員会資料をセットで確認する。
- 予算委員会要求資料は論点把握には有用だが、最終的に決まった予算そのものではない。可決状況は議案審議結果一覧、確定後の予算書・予算説明書は市公式サイトの予算ページで確認する。
- 予算は「使う予定・上限」であり、実際にどう使われたかは決算・行政報告書で確認する。個別契約や支払先まで追う場合は、入札・契約情報や情報公開請求も検討する。
- 公開資料でも個人名や請願者情報が含まれる場合がある。転載範囲、引用範囲、個人情報の扱いに注意する。
