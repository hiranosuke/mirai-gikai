## 3. マージ前に判明していた構造的差異（本マージで一部解消見込み）

1. **トピック分析が admin 内に2系統併存**
   - 系統1 `topic-analysis`（複数形テーブル `topic_analysis_versions/topics/classifications`）: インタビュー設定画面から起動、Next.jsサーバー内インライン実行（`/api/topic-analysis/run` → `after()`）。**web論点には繋がらない**。
   - 系統2 `user-topic-analysis`（単数形テーブル `topic_analysis_version/topic/topic_opinion`, `is_published`）: 直URL `/bills/[id]/user-topic-analysis` のみ（ナビ導線なし）、**GCP Cloud Run Job** で実行（`/api/user-topic-analysis/dispatch` → `executeTopicAnalysisJob`）。**web論点API/公開フロントが読む正系統**。
2. **公開論点の web 描画UIが未実装**（poc時点）: API＋adminのみ。
3. **当事者の意見ページ `/bills/[id]/opinions`** は個別レポート一覧で、**公開20件以上**（`MIN_PUBLIC_REPORTS_FOR_DISPLAY=20`、匿名性保護）で初表示。少数では0表示が正しい。

## 4. develop 側で確認済みの変化（マージで入る見込み）

- 公開論点フロント新設: `/bills/[id]/topics`（一覧）・`/bills/[id]/topics/[topicId]`（詳細）。`routes` に `billTopics`/`billTopicDetail` 追加。
- `/opinions` を `BillOpinionsPage`（user-topic-analysisベース・回答者一覧＋導線）へ差し替え。議案詳細に `bill-topics-preview-section`。

- **変わらない差異**: 2系統併存・user-topic-analysis は CloudRun 依存・admin ナビ入口なし。
